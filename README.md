# smartspark-social-bot

Public pages for SmartSpark, served by GitHub Pages:

- Privacy policy: https://smartsparkservices.github.io/smartspark-social-bot/privacy/
- Data deletion instructions: https://smartsparkservices.github.io/smartspark-social-bot/data-deletion/

Plain static HTML; edit and push to `main` to publish. The retention periods in the privacy
policy are commitments the SmartSpark backend implements (see `architecture.md` §26.2 in the
product repo), so change them there first.
